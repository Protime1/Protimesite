🔐 Protime1 SHA Checker

Что это?

Программа для проверки подлинности файлов. Она вычисляет SHA256 хеш файла и сравнивает его с базой сертификатов на GitHub.

Как это работает:

  • Вы выбираете файл для проверки
  • Программа вычисляет его SHA256 хеш
  • Ищет этот хеш в локальной базе и на GitHub
  • Если найден - показывает информацию о программе
  • Если нет - предлагает добавить новый сертификат

Пример сертификата:

Файл: CleanerPro2025.py
SHA256: 2682e13ed66fd07e80e2f0f4c570872e013f414efda468b0de0ab01a0fb09475
Программа: Cleaner Pro 2025
Издатель: GameDev
Версия: 1.0.0

При проверке файла программа покажет эти данные, подтверждая подлинность.
